# CareWatch downloads

CareWatch is a consent-led, local-first desktop app for body/pose monitoring, with a separately paired Android companion. Observations require human review. It is not a medical diagnosis, fall classifier, emergency-response replacement, or proof that food or medication was consumed.

## Downloads pending publication

There are **no public application downloads yet**. Windows and Android test packages are being reviewed for distribution. This page will provide verified download links when publication is cleared; it does not currently offer an installer or APK.

The planned Windows x64 build is unsigned; the Android APK is debug-signed and is not a Play Store release. Household cameras, physical phones, target hardware and away-from-home connectivity require supervised acceptance. No iOS, macOS or Linux download is available.

CareWatch keeps camera analysis local. Sources and remote sharing require explicit setup and approval. Phone access uses individual, revocable pairing credentials; remote video is opt-in. Private-network installation and enrollment are separate steps, not automatic router configuration.

## About this repository

This public repository contains release-page text only. Application source, history, internal reports, configuration, credentials and test data are not stored here. Any GitHub-generated archive of this repository contains only this page, **not the CareWatch application**.
